# 架构说明（对外版）

> 本文公开系统构成与数据流，不涉及源码、内部地址与客户信息。
> 版本：2026-10 对外版 v1.0

---

## 一、四个子系统

| 子系统 | 职责 | 交付形态 |
|---|---|---|
| **实时语音服务端** | 设备直连的实时媒体与对话编排：语音识别 → 大模型 → 语音合成、打断、会话上下文、工具调用、知识库检索、OTA/固件下发接口 | 源码 ＋ 依赖锁定 |
| **管理后台** | 唯一写库方：设备注册与鉴权、固件版本与激活、智能体与音色、模型配置、知识库、用户与权限 | 源码（可附构建产物） |
| **Web 控制台** | 运营人员界面，管理后台的前端 | 源码 / 静态产物 |
| **移动端** | 设备与智能体的移动侧管理（H5 / 小程序 / App） | 源码 |

**边界说明**：本产品不含机器人端固件与硬件。设备侧仅需遵循既有的音频与消息协议即可接入。

---

## 二、数据流（主链路）

```
设备上行音频 ──► 语音识别 ──► 大模型推理 ──► 语音合成 ──► 设备下行音频
                                   │
                                   └──► 知识库检索（按客户语料构建）
                                   └──► 工具调用（视所选模型能力）
```

- 上行／下行音频格式与帧长由服务端在会话建立时与设备协商；**不改变这套约定，设备端即可零改动**。
- 语音识别、大模型、语音合成均为**可插拔模块**，通过配置选择，不写死在代码里。
- 对话文本与音频是否留档、留多久，由配置与客户合规要求决定。

---

## 三、配置与差异外置（多客户 / 多环境）

设计原则：**统一代码，差异外置。**

| 差异类别 | 承载位置 |
|---|---|
| 本机默认项（对外地址、默认模块等） | 各环境配置文件 |
| 与后台的连接参数 | 各环境外置配置 |
| 智能体 / 模型 / 音色 / 提示词（设备实际生效的配置） | 管理后台数据库，**不随代码部署** |
| 运行环境（运行时版本与依赖） | 各环境独立 |
| 域名、证书、反向代理 | 各环境独立 |

**多客户与多场景**：系统按"用户 ＋ 智能体"做归属与访问控制，一套部署可服务多个场景；
若客户要求**强隔离（独立数据分区、独立配额、独立管理员）**，则以独立部署一套的方式交付。

---

## 四、部署拓扑

| 拓扑 | 适用 |
|---|---|
| **单机部署**（服务端 ＋ 后台 ＋ 数据库 ＋ 缓存 ＋ 知识库组件同机） | 中小规模、内网、快速上线 |
| **拆分部署**（语音服务、后台与数据库、知识库分别部署） | 规模较大或对可用性有要求 |
| **纯内网部署**（模型走客户自有平台，无公网出口） | 数据不出域要求强的客户 |

各拓扑均默认执行：端口收敛、设备鉴权开启、服务开机自启、证书自动续期。

---

## 五、接入前置条件

1. 客户侧服务器满足《部署最低要求》；
2. 若使用客户自有模型平台：提供**接入文档与测试账号**，用于联调验证（重点验证 OpenAI 兼容性与函数调用）；
3. 提供**设备参考机与固件版本**，用于设备端联调；
4. 域名与证书就绪（WSS 依赖）。

> 前置条件未就绪时不排期、不承诺上线日期。
